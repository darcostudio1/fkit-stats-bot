# FK!T Stats Web App

A modern, beautiful web application for viewing and searching Game of Thrones Conquest alliance stats, powered by Supabase.

## Features
- Clean, responsive Material UI table
- Filter, sort, and search player stats
- Live data pulled from Supabase
- Mobile-friendly

## Setup (on Replit)
1. Place your Supabase URL and anon key in a `.env` file (or directly in the code for public viewing).
2. Run `npm install` to install dependencies.
3. Run `npm start` to launch the app.

## Deployment
- You can use Replit's web server to host the app for free alongside your Discord bot.
